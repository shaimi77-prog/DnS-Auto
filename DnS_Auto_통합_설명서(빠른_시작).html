DnS Auto 통합 설명서 (빠른 시작)

직접 실행과 AI 연동에 필요한 최소 절차를 한 화면에서 확인하는 안내서입니다.

1. 직접 실행

  1. 배포받은 DnS Auto 폴더 전체를 원하는 위치에 복사합니다.
  2. DnS Auto.exe를 더블클릭합니다.
  3. PDF 취합, Excel 취합 또는 파일 변환 기능을 선택합니다.
  4. 중요한 원본 대신 작업용 사본으로 먼저 확인합니다.

2. AI 연동

  1. DnS Auto MCP.exe는 일반적으로 직접 더블클릭하지 않습니다.
  2. Codex 등 MCP 지원 AI의 설정에 실행 파일의 절대경로를 등록합니다.
  3. 처리할 파일은 inputs, 결과는 outputs, 공유 설정은 profiles 폴더를 사용합니다.

3. 공통 주의사항

  • EXE만 따로 옮기지 말고 DnS Auto 폴더 전체를 유지하세요.
  • _internal 폴더의 파일과 폴더 구조를 변경하지 마세요.
  • 폴더 위치를 옮기면 AI 프로그램의 MCP 실행 경로도 수정하세요.
  • DOCX, HWP/HWPX 또는 XLS 변환에는 해당 Office 프로그램이 설치되어 있어야 합니다.
