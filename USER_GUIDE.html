DnS Auto 통합 포터블 사용자 설명서

이 배포본에는 사용자가 직접 실행하는 프로그램과 AI가 호출하는 MCP 서버가 함께 들어 있습니다. 두 프로그램은 동일한 프로필 폴더를 공유합니다.

1. 두 실행 파일의 차이

실행 파일언제 사용하나요?실행 방법
DnS Auto.exe사용자가 화면에서 직접 파일을 선택하고 설정·취합할 때더블클릭
DnS Auto MCP.exeCodex, Claude Desktop, Cursor 등 로컬 MCP 지원 AI가 DnS Auto를 호출할 때AI의 MCP 설정에 한 번 등록하며 일반적으로 직접 실행하지 않음

중요: 두 EXE 중 하나만 따로 꺼내지 말고 DnS Auto 폴더 전체를 유지하세요.

3. 공유 프로필

DnS Auto.exe에서 저장한 프로필은 profiles\sheet 또는 profiles\pdf에 저장됩니다. DnS Auto MCP.exe도 같은 폴더를 읽으므로 프로필을 복사하거나 다시 만들 필요가 없습니다.

5. PDF/OCR 최신 동작

PDF 취합 모드는 신속·표준·신중으로 나뉘며 표준이 기본값입니다. 신속은 OCR 없이 완전한 네이티브 행만 적재하고, 신중은 이미지 문자를 더 크게 분석하는 실험적 기능입니다.

GUI에서 PDF 취합을 새로 설정할 때 자동 추천된 기준 파일·페이지를 자유롭게 바꿀 수 있습니다. 텍스트 PDF는 기존 텍스트를 우선 사용하고 이미지 PDF 값 영역은 210 DPI 기본 OCR로 판독합니다. 저대비이면서 흐린 영역과 같은 헤더의 형식 이상치만 조건부로 선명화 보강하며, 기본·보강 결과가 모두 비고 문자성 잉크가 있을 때만 더 큰 검출 크기로 재시도합니다. 기준 단어는 전체 페이지 150 DPI OCR 결과에서 5단계로 찾고, 찾지 못하면 최대 탐색 영역을 210 DPI로 한 번만 재시도한 뒤에도 없을 때 저장된 절대좌표를 사용합니다. 회전·기울기 보정과 OCR 캐시는 현재 페이지만 대상으로 하며 다른 파일로 전달되지 않습니다. 자세한 절차와 확인 기준은 GUI_GUIDE.html을 확인하세요.

6. 공통 주의사항

  • Windows용 포터블 프로그램입니다.
  • 중요한 원본 대신 사본을 사용하세요.
  • DOCX, HWP/HWPX 또는 XLS 문서 변환은 해당 프로그램이 PC에 설치되어 있어야 합니다.
  • _internal 폴더와 mcp_policy.json은 용도를 모르면 수정하지 마세요.

PDF 취합 모드

모드동작
신속 — OCR 건너뛰기PDF에 포함된 문자만 사용합니다. 매핑 필드 하나라도 추출되지 않으면 해당 페이지 행 전체를 제외하며 빈 행을 만들지 않습니다.
표준 — 기본값PDF 문자를 우선 사용하고 이미지 문자는 현재 기본 OCR 정책으로 인식합니다.
신중 — 실험적이미지 문자를 표준보다 조금 더 크게 분석합니다. 시간이 늘 수 있으며 정확도 향상을 보장하지 않습니다.

프로그램 시작 시 항상 표준 모드입니다. 모드는 PDF 취합에만 적용되고 프로필에 저장되지 않습니다. 신속 모드는 정상 빈 필드가 있는 양식도 행 전체를 제외할 수 있습니다.
