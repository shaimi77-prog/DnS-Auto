DnS Auto MCP 사용자 설명서 - AI 연동용

이 프로그램은 무엇인가요?
MCP를 지원하는 AI 프로그램이 Excel 취합, PDF/OCR 취합, 문서 변환 같은 DnS Auto 기능을 사용할 수 있도록 연결해 주는 프로그램입니다. 버튼을 누르는 일반 화면은 없으며 연결된 AI 프로그램이 뒤에서 자동으로 실행합니다.

1. 시작하기 전에

  • Windows용 프로그램입니다.
  • 압축을 푼 폴더는 통째로 보관해야 합니다.
  • DOCX, HWP/HWPX 또는 XLS 문서 변환은 해당 프로그램이 PC에 설치되어 있어야 합니다.
  • DnS Auto MCP.exe를 더블클릭해도 일반 화면이 나오지 않는 것이 정상입니다.

2. 설치하기

  1. DnS_Auto_Portable.zip을 마우스 오른쪽 버튼으로 클릭합니다.
  2. 모두 압축 풀기를 선택하고 원하는 위치를 정합니다.
  3. 압축을 푼 폴더 안에 다음 항목이 있는지 확인합니다.
DnS Auto
├─ DnS Auto.exe              사용자 직접 실행용
├─ DnS Auto MCP.exe          AI 연동용
├─ inputs
├─ outputs
├─ profiles
│  ├─ sheet
│  └─ pdf
├─ _internal
├─ mcp_policy.json
└─ 사용자_설명서.html

주의: EXE만 따로 꺼내지 마세요. 폴더 전체를 이동하거나 EXE의 바로가기를 만드세요.

3. AI 프로그램에 연결하기

사용할 AI 제품에 맞는 방법을 선택해 DnS Auto MCP를 등록합니다. 모든 예시의 EXE 경로는 실제 압축 해제 위치로 바꾸세요.

Codex

  1. DnS Auto MCP.exe를 Shift 키를 누른 채 마우스 오른쪽 버튼으로 클릭하고 경로로 복사를 선택합니다.
  2. C:\Users\사용자이름\.codex\config.toml을 메모장으로 엽니다.
  3. 맨 아래에 다음 내용을 붙이고 command를 실제 EXE 경로로 바꿉니다.
[mcp_servers.dns-auto]
command = 'D:\DnS Auto\DnS Auto MCP.exe'
args = []
  1. 저장한 뒤 Codex를 완전히 종료하고 다시 실행합니다.

폴더를 옮기면 command 경로만 새 위치로 바꾸면 됩니다.

DnS Auto MCP는 특정 AI 제품에 종속되지 않은 Windows 로컬 stdio MCP 서버입니다. 아래 제품도 같은 PC에서 로컬 MCP 실행을 지원하므로 연결할 수 있습니다.

Claude Desktop

Claude Desktop의 개발자 설정에서 설정 파일을 연 뒤 mcpServers에 추가합니다. Windows의 전통적인 설정 파일 이름은 claude_desktop_config.json입니다.

{
  "mcpServers": {
    "dns-auto": {
      "command": "D:\\DnS Auto\\DnS Auto MCP.exe",
      "args": []
    }
  }
}

Anthropic MCP 공식 안내

Cursor

전체 프로젝트에서 쓰려면 사용자 홈의 .cursor\mcp.json, 특정 프로젝트에서만 쓰려면 프로젝트의 .cursor\mcp.json에 추가합니다.

{
  "mcpServers": {
    "dns-auto": {
      "command": "D:\\DnS Auto\\DnS Auto MCP.exe",
      "args": []
    }
  }
}

Cursor MCP 공식 안내

Visual Studio Code / GitHub Copilot

명령 팔레트에서 MCP: Add Server를 실행하거나, 작업 폴더의 .vscode\mcp.json 또는 사용자 MCP 설정에 추가합니다.

{
  "servers": {
    "dns-auto": {
      "type": "stdio",
      "command": "D:\\DnS Auto\\DnS Auto MCP.exe",
      "args": []
    }
  }
}

VS Code MCP 공식 안내

Cline

Cline의 MCP Servers 화면에서 Configure MCP Servers를 선택하여 cline_mcp_settings.json을 열고 추가합니다.

{
  "mcpServers": {
    "dns-auto": {
      "command": "D:\\DnS Auto\\DnS Auto MCP.exe",
      "args": [],
      "alwaysAllow": [],
      "disabled": false
    }
  }
}

Cline MCP 공식 안내

공통 확인 방법

  1. 설정 파일을 저장합니다.
  2. AI 프로그램을 완전히 종료하고 다시 실행합니다.
  3. MCP 서버 또는 도구 목록에서 dns-auto를 확인합니다.
  4. inputs의 파일을 검사해 줘라고 요청해 연결을 시험합니다.

연결할 수 없는 경우: 브라우저에서만 실행되는 AI, 로컬 EXE 실행을 지원하지 않는 앱, 원격·화면 없는 환경에서는 이 포터블 EXE를 직접 연결할 수 없습니다. 사용자 개입형 작업은 Windows 화면을 표시할 수 있어야 하며, 원격 환경에서는 저장된 profile.json을 사용하는 무인 실행이 적합합니다.

제품 업데이트로 메뉴 이름이나 설정 위치가 달라질 수 있습니다. 형식이 바뀌면 위 공식 안내 링크에서 최신 local stdio server 설정을 확인하세요.

4. 처리할 파일 준비하기

처리할 파일은 inputs에, 저장 프로필은 종류에 따라 profiles\sheet 또는 profiles\pdf에 둡니다. 중요한 원본 대신 사본을 사용하는 것이 안전합니다.

작업준비할 파일
Excel 취합취합 양식, 원본 Excel, Sheet 프로필 JSON
PDF/OCR 취합취합 양식, PDF, PDF 매핑 프로필 JSON
문서 변환DOCX, HWP/HWPX 또는 XLS

하위 폴더를 만들어도 됩니다. 예: inputs\2026년 7월 자료

파일명과 원하는 작업을 평소 말하듯 구체적으로 적습니다.

PDF 취합 예시

inputs의 4월과 5월 PDF를 취합양식.xlsx에
pdf_profile.json 설정대로 취합해 줘.

문서 변환 예시

inputs 폴더의 보고서.docx를 PDF로 변환해 줘.

완료된 파일은 outputs 폴더에 저장됩니다.

6. 프로필 없이 대화형으로 사용하기

처음 사용하는 양식이거나 저장된 profile.json이 없어도 사용할 수 있습니다. 사용하는 AI 프로그램에 “프로필 없이 대화형으로 취합해 줘”라고 요청하세요.

Excel 대화형 취합

  1. AI 프로그램이 DnS Auto 설정 창을 엽니다.
  2. 취합할 시트를 선택합니다.
  3. 각 시트의 헤더 시작 행과 끝 행, 취합 방식을 지정합니다.
  4. 확인을 누르면 MCP가 자동으로 취합을 계속합니다.
  5. 원하면 설정을 profile.json으로 저장해 다음부터 무인 실행에 사용할 수 있습니다.

예를 들어 “A폴더의 양식.xlsx에 B폴더의 파일들을 취합해 줘”라고만 요청하면 MCP가 호환 프로필을 검색합니다. 호환 프로필이 발견되면 사용할지 또는 대화형으로 진행할지 반드시 확인하며, 프로필을 임의로 선택하지 않습니다. 원하는 방식을 바로 지정하려면 아래처럼 요청하세요.

A폴더의 양식.xlsx에 B폴더의 Excel 파일들을 취합해 줘.
저장된 Sheet 프로필은 사용하지 말고 설정 창을 열어 대화형으로 진행해 줘.

PDF 대화형 취합

  1. 시트와 헤더 범위를 지정합니다.
  2. 표시된 PDF에서 각 헤더에 대응하는 영역을 마우스로 드래그합니다.
  3. 필요한 필드 설정을 마치면 취합이 자동으로 이어집니다.
  4. 완성한 영역 설정은 profile.json으로 저장할 수 있습니다.
A폴더의 양식.xlsx에 B폴더의 PDF 파일들을 취합해 줘.
저장된 PDF 프로필은 사용하지 말고 영역 설정 창을 열어 대화형으로 진행해 줘.

설정 창이 열려 있는 동안 AI 프로그램의 작업 상태는 사용자 입력 대기로 표시됩니다. 창에서 확인하면 작업이 계속되고, 취소하면 AI 프로그램에 취소 결과가 전달됩니다.

7. 요청을 처리하기 전 자동 검색과 확인

취합 요청을 받으면 MCP의 discover_merge_plan 도구가 실행 전에 포터블 폴더를 조사합니다. AI가 파일이나 프로필을 임의로 고르지 않도록 이 판정은 MCP 서버 자체에서 수행됩니다.

  1. inputs와 모든 하위 폴더에서 Excel·PDF 파일을 검색합니다.
  2. 파일 종류를 바탕으로 Excel 취합 또는 PDF 취합인지 판별합니다.
  3. 기준 양식 후보와 원본 파일 후보를 분리합니다.
  4. profiles\sheet 또는 profiles\pdf에서 유형·양식명·시트가 맞는 프로필을 검색합니다.
  5. 불명확한 항목이 있으면 작업을 시작하지 않고 질문 목록을 반환합니다.
  6. 출력 경로를 따로 지정하지 않으면 outputs를 사용합니다.
상황MCP 동작
양식 후보가 여러 개임의로 고르지 않고 사용할 양식을 질문
입력 폴더·원본 범위가 불명확경로 또는 파일 범위를 질문
호환 프로필이 1개 이상 발견됐지만 사용자가 지정하지 않음프로필 목록을 보여주고 사용할지 또는 대화형으로 진행할지 질문
호환 프로필이 없음대화형 설정 창을 열지 확인
사용자가 프로필명을 명시다른 프로필을 묻지 않고 해당 프로필의 호환성을 검증한 후 진행
사용자가 “대화형”이라고 명시프로필을 선택하지 않고 설정 창을 여는 방식으로 진행

중요: “프로필명 명시” 또는 “대화형 명시”는 프로필 선택 질문만 생략한다는 뜻입니다. 양식이 여러 개이거나 원본 범위가 불명확하면 안전을 위해 계속 확인합니다.

반환 상태의 의미

상태의미

inputs에 있는 양식과 원본 파일을 확인해서 취합해 줘.

이 요청은 먼저 파일과 호환 프로필을 조사하고, 필요한 경우 사용자에게 선택을 요청합니다.

inputs\취합양식.xlsx에 inputs\7월자료의 Excel 파일들을
월별취합 프로필로 취합해 줘.

프로필 사용 여부를 묻지 않고 PDF 설정·영역 드래그 창을 엽니다.

PDF/OCR 처리와 진행 통계

저장 프로필 방식과 대화형 방식은 GUI와 동일한 공용 PDF/OCR 엔진을 사용합니다. MCP에 별도의 OCR 캐시나 충분성 판정 알고리즘을 두지 않습니다. 이미지 PDF 값 영역은 210 DPI 기본 OCR로 판독하고 필요한 영역만 조건부 보강합니다. 기준 단어의 150 DPI 5단계 검색이 실패하면 최대 탐색 영역을 210 DPI로 한 번만 재시도하며, 그래도 찾지 못하면 저장된 절대좌표를 사용합니다.

진행 ETA에는 실제 OCR 호출과 재시도가 반영됩니다. 완료 결과의 details에는 전체 페이지 OCR, 앵커 주변 재시도, 값 영역 기본·보강·대형 검출 재시도와 선택 통계가 포함될 수 있습니다. 진행 이벤트와 결과 메타데이터에는 OCR 원문을 기록하지 않습니다. 취소·완료·실패 후에는 작업 캐시를 초기화하므로 다음 MCP 작업과 공유되지 않습니다.

9. 문제가 생겼을 때

AI 프로그램에서 DnS Auto 도구가 안 보여요

  • 사용 중인 AI 제품의 MCP 설정에서 EXE 경로가 실제 위치와 같은지 확인합니다.
  • 제품별 설정 형식과 command, args 항목을 다시 확인합니다.
  • AI 프로그램을 완전히 종료한 뒤 다시 실행합니다.
  • 제품에 MCP 서버 상태 또는 로그 화면이 있다면 dns-auto의 오류 내용을 확인합니다.

“허용 입력 폴더 밖”이라고 나와요

파일을 이 프로그램의 inputs 폴더로 복사하고 다시 요청하세요.

EXE가 실행되지 않아요

  • ZIP 안에서 바로 실행하지 말고 먼저 모두 압축 풉니다.
  • _internal이 EXE와 같은 폴더에 있는지 확인합니다.
  • 백신 프로그램이 파일을 격리했는지 확인합니다.

작업 결과를 찾을 수 없어요

  • outputs 폴더를 새로고침합니다.
  • 사용 중인 AI 프로그램에 “작업 상태와 실패 이유를 알려줘”라고 요청합니다.
  • 결과 파일과 같은 이름의 Excel 파일이 이미 열려 있다면 닫고 다시 시도합니다.

10. 이동하거나 삭제하기

이동: 폴더 전체를 옮기고 사용 중인 AI 프로그램의 MCP 설정에서 command를 새 EXE 경로로 수정합니다.

삭제: 필요한 outputs 결과를 보관한 뒤 폴더 전체를 삭제합니다. 별도 제거 프로그램은 없습니다.

11. 안전한 사용 요령

  • 중요한 원본 대신 사본을 inputs에 넣습니다.
  • 결과를 확인한 뒤 실제 업무 파일에 반영합니다.
  • 용도를 모르면 _internal과 mcp_policy.json을 수정하지 않습니다.
