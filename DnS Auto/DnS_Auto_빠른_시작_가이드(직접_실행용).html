DnS Auto 빠른 시작 가이드 - 직접 실행용

목적: 처음 사용하는 분이 DnS Auto.exe를 실행해 PDF 또는 Excel 취합을 빠르게 완료할 수 있도록 핵심 순서만 안내합니다. 세부 설정과 오류 조치는 GUI 사용자 설명서를 확인하세요.

1. 실행 전 확인

  1. 배포 ZIP을 원하는 위치에 모두 압축 해제합니다.
  2. DnS Auto 폴더 안의 DnS Auto.exe를 더블클릭합니다.
  3. 원본은 별도로 보관하고 작업용 사본을 사용합니다.
  4. 기준 Excel 양식과 입력 파일을 모두 닫습니다.
  5. 암호가 설정된 파일은 미리 해제합니다.
  6. 대표 파일 2~3개로 먼저 시험한 후 전체 파일을 처리합니다.

2. PDF 파일 취합

준비할 파일

  • 기준 Excel 양식(.xlsx 또는 .xlsm)
  • 표 구조가 같거나 유사한 PDF
  • 양식의 헤더 시작 S행과 끝 E행

PDF 취합 모드

표준이 기본값입니다. OCR을 건너뛰려면 신속, 이미지 문자를 더 크게 분석하려면 신중(실험적)을 선택합니다.

  1. PDF 파일 취합(Drag)을 선택합니다.
  2. 기준 Excel 양식을 선택하고 취합할 시트·그룹·S행·E행을 지정합니다.
  3. 미리보기에서 헤더 범위를 확인하고 시트별 PDF를 선택합니다.
  4. 자동 추천된 기준 파일·페이지를 확인하고, 필요하면 이전·다음 파일/페이지 버튼으로 원하는 페이지를 선택합니다. 버튼은 처음과 끝에서 양방향으로 순환하며, 미리보기는 창 가로폭에 맞고 세로는 스크롤됩니다.
  5. 선택한 기준 페이지에서 안내되는 Excel 열에 해당하는 실제 값 영역을 드래그합니다.
  6. 위치가 페이지마다 달라지면 가까운 고정 문구를 기준 단어로 입력합니다.
  7. 같은 문구가 여러 개면 다음으로 위치를 확인한 뒤 확정합니다.
  8. 모든 열을 지정하면 자동 취합이 시작됩니다.
OCR 기준 페이지: 판독 유형이 [OCR 필요]이면 확정 시 안내가 한 번 표시됩니다. 영역 드래그와 기준 단어 입력은 기존과 같이 기준 페이지에서 한 번만 수행합니다.
이미지 PDF 판독: 값 영역은 210 DPI 기본 OCR로 판독하고 저대비·흐림 또는 같은 헤더의 형식 이상치일 때만 조건부 보강합니다. 기준 단어를 5단계에서 찾지 못하면 최대 탐색 영역을 210 DPI로 한 번 더 확인하며, 그래도 없으면 저장된 절대좌표를 사용합니다.
회전·기울기: 이미지 페이지는 페이지별 자동 보정과 기준 앵커 검증을 거칩니다. 검증에 실패한 보정은 적용하지 않고 해당 페이지를 제외하며 감사 로그에 사유를 기록합니다.
반복 작업: 설정을 profiles\pdf에 저장하면 다음 작업에서 다시 드래그하지 않고 불러올 수 있으며, 같은 프로필을 MCP에서도 사용할 수 있습니다.

3. Excel 파일 취합

  1. Excel 파일 취합(Sheet)을 선택합니다.
  2. 기준 Excel 양식을 선택합니다.
  3. 취합할 시트와 S행·E행을 지정하고 미리보기의 주황색 헤더 범위를 확인합니다.
  4. 업무 목적에 맞는 취합 방식을 선택합니다.
  5. 데이터 지정 입력이면 기준 열과 빈칸만 채우기 여부를 지정합니다.
  6. 취합 대상 Excel 파일을 선택합니다.
  7. 완료 후 결과의 첫 행·중간 행·마지막 행을 확인합니다.
방식언제 사용하나요?
데이터 누적 적재여러 파일의 행을 기준 양식 아래에 차례대로 추가할 때
데이터 지정 입력기관명·접수번호처럼 같은 기준값의 행을 찾아 입력할 때
빈칸만 채우기기준 양식의 기존 값과 수식을 유지하고 빈 셀만 채울 때
반복 작업: Sheet 설정은 profiles\sheet에 저장할 수 있으며 GUI와 MCP가 함께 사용합니다.

4. 진행 상황과 결과 확인

진행 창에 현재 파일·페이지, 처리 상태, 경과 시간과 예상 잔여 시간이 표시됩니다. OCR 처리 중에는 일반 PDF보다 오래 걸릴 수 있으므로 프로그램을 강제로 종료하지 마세요.

직접 실행한 GUI 결과는 기준 Excel 양식과 같은 폴더에 생성됩니다. 첫 번째·중간·마지막 데이터 행, 날짜와 번호, OCR의 0/O·1/I, 기준 열 대응 여부와 실패·제외 파일을 확인하세요.

5. 문제가 있을 때

증상우선 조치
PDF 글자가 깨짐표준 모드로 다시 처리하거나 신중(실험적) 모드를 비교
OCR 결과가 비거나 잘림글자 전체와 여러 줄이 포함되도록 영역을 다시 지정
기준 단어 위치가 다름다음으로 후보를 확인하거나 더 가까운 문구 사용
Excel 결과가 없음시트명, S행·E행, 취합 방식과 입력 데이터 확인
.xls만 실패Microsoft Excel 설치 상태를 확인하거나 XLSX로 먼저 변환

자세한 프로필 관리, 교차매핑, 문서 변환, 보안·개인정보 처리와 오류 조치는 DnS_Auto_사용자_설명서(직접_실행용).html을 확인하세요.

통합 사용자 설명서상세 GUI 설명서

PDF 취합 모드

모드동작
신속 — OCR 건너뛰기PDF에 포함된 문자만 사용합니다. 매핑 필드 하나라도 추출되지 않으면 해당 페이지 행 전체를 제외하며 빈 행을 만들지 않습니다.
표준 — 기본값PDF 문자를 우선 사용하고 이미지 문자는 현재 기본 OCR 정책으로 인식합니다.
신중 — 실험적이미지 문자를 표준보다 조금 더 크게 분석합니다. 시간이 늘 수 있으며 정확도 향상을 보장하지 않습니다.

프로그램 시작 시 항상 표준 모드입니다. 모드는 PDF 취합에만 적용되고 프로필에 저장되지 않습니다. 신속 모드는 정상 빈 필드가 있는 양식도 행 전체를 제외할 수 있습니다.
